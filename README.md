# Sales Analytics Dashboard 📊

## 📌 Project Overview
This repository contains a **Power BI dashboard** built from a structured sales dataset.  
The dashboard provides actionable insights into sales performance across regions, product categories, customer types, and sales channels.  

It is designed to help business stakeholders quickly identify trends, measure profitability, and evaluate sales strategies.

---

## 📂 Dataset Details
The dataset includes:
- Product_ID, Sale_Date, Month  
- Sales_Person & Region  
- Sales_Amount & Quantity_Sold  
- Product_Category (Furniture, Food, Clothing, Electronics)  
- Unit_Cost, Unit_Price, Profit  
- Customer_Type (New / Returning)  
- Payment_Method (Cash, Credit Card, Bank Transfer)  
- Sales_Channel (Online / Retail)  

---

## 📊 Dashboard Features
The dashboard leverages multiple interactive visuals:
- **Pie Charts** – Customer segmentation (New vs Returning), Payment method distribution.  
- **Bar/Column Charts** – Monthly sales trends, Salesperson performance, Product category comparisons.  
- **Maps** – Regional sales distribution across North, South, East, and West.  
- **Slicers** – Dynamic filtering by month, region, product category, and sales channel.  
- **Navigation Bar** – Easy page switching for a professional, app-like experience.
